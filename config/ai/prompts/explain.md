# Explain a file or topic

If the target is a file, start with its role in the architecture and how it is
reached. Explain its important functions, inputs, outputs, dependencies, and
side effects. Trace a representative path through it and its immediate callers
and callees. Explain the problem it solves and why its important choices
matter. Focus on concepts rather than a line-by-line paraphrase.

If the target is a topic, explain it directly. Use repository evidence when the
topic refers to this codebase. Otherwise, give a general explanation and a
small example; do not imply that the topic appears in this repository. Answer
the learner's follow-up questions in the same session, using the shared study
and language rules.

# Interactive quiz

Inspect the target file or repository-related topic. Give a brief
architectural introduction, then ask one question at a time and wait for the
learner's answer. Start with purpose and flow, then move to important
functions, tradeoffs, and consequences of changes. Give feedback with exact
file/function references after each answer. Offer hints before revealing
solutions. Do not reveal an answer key up front or invent code for a topic
that is not present in the repository.
